# NEO GBA v0.17.0

## Novidades
- ROMs autorizadas armazenadas no IndexedDB;
- abrir ROM diretamente pela biblioteca;
- remover ROM da biblioteca;
- perfis por jogo;
- filtro Pixel Perfect / Suave;
- integer scaling Auto/1x/2x/3x/4x;
- preferências de vídeo salvas por jogo.

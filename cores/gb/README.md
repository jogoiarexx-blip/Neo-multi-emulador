# NEO GB

Núcleo independente para Game Boy e Game Boy Color.

- Engine: EmulatorJS + Gambatte
- Formatos: `.gb`, `.gbc`
- Entrada: `index.html?autoload=<url>&game=<titulo>`
- Runtime fixado no EmulatorJS 4.2.3 via CDN.

Este módulo pode ser atualizado separadamente dos demais núcleos do NEO Multi.
